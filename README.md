# Ral & Birgi: storm tracker

One-page turn tracker for a mono-red Storm deck in Magic: The Gathering: Ral, Monsoon Mage plus Birgi, God of Storytelling.

- Mana pools for red, blue, white and Birgi red (Birgi's mana survives phase changes), plus the total
- Storm count
- Instant / Sorcery buttons that count storm and flip Ral's coin; an Other spell button that counts storm only
- Birgi toggle (each cast adds {R}), Ral state (Monsoon Mage / flipped / not in play), My turn toggle
- Next phase, End turn, Undo, New game; saves itself if the phone locks

Open it at https://huginn-alder.github.io/ral-storm-tracker/ and use "Add to Home screen" to install it. Once it's been opened online, it works offline too.
